CertVault · CA 证书 / 账号凭证管理（Windows 桌面版 v1.5）
==========================================================================

一、这是什么
  管理公司各个招投标 / 交易平台账号与 CA 证书口令的台账工具，重点解决三件事：
    1) 把平台名称、网址、账户、密码、CA 口令、截止有效期、提醒天数、备注集中记下来；
    2) 到期自动提醒（未登记 / 正常 / 提醒中 / 已逾期 四档状态）；
    3) 每个平台可以附多张「平台操作截图」，方便交接和排错；
    4) 记下平台所属「地区」，在地图上一眼看清 CA 都分布在哪些省、哪些已经过期。
  数据完全存在你自己的文件夹里，不联网、不上传、不需要账号登录。

二、运行环境
  · Windows 10 / 11（64 位）
  · Microsoft Edge WebView2 运行时（Win11 一般已自带；若提示缺少，装一次即可：
    https://developer.microsoft.com/microsoft-edge/webview2/ ）
  · 不需要安装，不需要 .NET 开发环境，不需要联网。

三、第一次使用
  1. 把整个「CertVault-桌面版」文件夹拷到任意位置（本机磁盘、U 盘、共享盘都行）；
  2. 双击 CertVault.exe；
  3. 弹出「选择数据文件夹」时选一个目录（默认建议 我的文档\CertVault数据）；
     选定后，这个目录里会自动生成：
        data\certvault.json   台账数据
        data\settings.json    设置（托盘 / 弹窗间隔等）
        data\audit.json       操作日志
        images\<记录ID>\      截图文件（按记录分目录）
        backup\               危险操作前自动备份（保留最近 10 份）
  4. 开始「+ 新增」录入。

四、数据怎么放、怎么带走
  · 程序文件夹（exe 那套）和数据文件夹是分开的：换电脑只拷数据文件夹也够；
  · 整个数据文件夹可以直接拷走 / 备份 / 放到 NAS 共享目录；
  · 多人各自一份：每人一个自己的数据文件夹，互不干扰；
  · 注意：不要两个人同时打开同一个数据文件夹（文件会互相覆盖），也不要把数据文件夹放进
    会自动同步的网盘目录里同时开两份程序。
  · 关闭程序后再拷贝，最稳妥（右下角托盘图标 → 退出）。

五、主要功能
  · 台账：新增 / 编辑 / 删除（可多选）；点行看详情抽屉；序号自动连续，删掉一行后面自动补位；
  · 状态与提醒：截止有效期 +「提醒天数」（默认 60 天）自动算剩余天数，分为
      未登记（没填有效期）/ 正常 / 提醒中（剩余 ≤ 提醒天数）/ 已逾期；
  · 到期提醒：启动后自动汇总弹窗；弹窗冷却间隔可在「设置」里改为 1 / 4 / 12 / 24 小时；
    「取消提醒」只是不再弹窗，状态照常计算；
  · 截图：每条可附多张平台操作截图，列表显示张数，详情里点开原图；
  · 右键复制：在表格行上点右键，可直接复制平台名称 / 网址 / 账户 / 密码 / CA 口令 / 截止有效期；
  · 地区与地图：
      编辑记录的「地区」是可搜索组合框：直接输入「内蒙」就筛出「内蒙古」，输入「广东省」归到「广东」
      （短名 / 官方全名 / 别名都认）；也可点「省份」展开 34 省列表，点「识别」按名称 / 网址 / 备注自动猜；
      工具栏「地图」按钮切到中国地图，按省份上色（红=有逾期、金=提醒中、绿=正常、灰=未登记）；
      鼠标指向省份看该省几条记录、都是谁；点省份 = 只筛这一省，再点一次取消；
      右侧列表按条数排序，点条目同样能筛选；地图可滚轮缩放、拖动平移（纯离线，不联网）；
      地图开着时导入 Excel 或改地区，「按地区汇总」与「已定位」计数会自动重算，不用退出地图。
  · Excel：
      「导出模板」得到空白 xlsx（只有表头，可直接填写后导入）；
      「Excel 导入」支持 .xlsx / .xls / .csv，导入前会先预检（新增几条、覆盖几条、错误几行），预检里三块明细都能点开：
      新增明细、覆盖明细（字段 旧值 → 新值，密码 / CA 口令只显示「已填写 / 空」）、错误明细（第几行 + 原因）；
      「全量导出」把当前台账导成 xlsx（工作表名 CA 台账）。
      截图也会一起写进 Excel：每条记录的截图排在 K 列往右（截图 1、截图 2 …），
      直接嵌在单元格里，打开就能看到；拿这份 Excel 导入时，图片会重新落回 images 目录。
  · 顶部 KPI 卡片：总数 / 已逾期 / 提醒中 / 未登记有效期四张卡都能点；
      点「已逾期」台账立即只筛逾期，「提醒中」「未登记」同理，点「总数」恢复全部。
  · 打开数据文件夹（三处都能点）：
      状态栏左下「数据目录 · 文件夹名」、顶部标签「数据文件夹 · 名字」、设置里「打开文件夹」；
      导出 / 导入完成后的提示条右侧也有一个「打开所在文件夹 / 打开数据文件夹」按钮，点一下直接用资源管理器定位。
  · 设置：关闭窗口是否最小化到托盘、开机自启、弹窗冷却间隔、数据目录体检；
  · 日志：所有新增 / 修改 / 删除 / 导入 / 导出 / 备份都有记录。

六、Excel 模板填写规则
  列顺序（共 9 列，第 1 行是表头，不要改列名）：
    平台名称* | 网址 | 账户 | 密码 | CA口令 | 截止有效期 | 提醒天数 | 备注 | 地区
  · 「地区」填省级简称即可（北京 / 内蒙古 / 广西 / 宁夏 …），留空则该记录不上地图；
    老版本导出的 8 列文件照能导入，导入后地区为空，编辑里补一下即可；
  · 平台名称为空的行会被跳过；
  · 截止有效期写 2026-02-20 或 2026/2/20 都可以；留空表示「未登记」；
  · 提醒天数写数字（1–365），留空按 60 天；
  · 判重规则：网址 + 账户相同的记录视为同一条，导入时覆盖原记录（不新增重复行）；
  · 导入采用「逐行处理」：某一行有问题只跳过那一行，其余照常导入，并在预检里列出错误行。

七、安全说明（重要）
  · 密码与 CA 口令以明文保存在 data\certvault.json 中，程序没有加密，也不联网；
    请把数据文件夹放在有访问权限控制的位置，不要把台账连同密码发到公共群/邮箱；
  · 界面默认遮挡密码，点「显示密码」才展开；复制密码后 30 秒内若剪贴板内容未变会自动清空；
  · 批量删除、清空、导入前会自动写一份 backup\<时间>-<原因>.json。

八、托盘与开机自启
  · 左键单击托盘图标 = 立即显示主窗口（不用先右键，也不必双击）；
  · 最小化 — 只是收到任务栏，点任务栏图标即可还原（旧版会藏起来，像被关掉）；
  · 点窗口右上角关闭 = 收进托盘（程序仍在后台，提醒照常工作）；
  · 托盘图标右键：显示主窗口 / 开机自动启动 / 打开程序所在文件夹 / 退出；
  · 开机自启是写入当前用户的启动项（HKCU\...\Run），不写系统服务；程序文件夹搬家后
    重新勾选一次即可指向新路径。

九、常见问题
  · 双击后提示缺少 WebView2 运行时：按第三节装一次运行时，再打开；
  · 提示「数据文件夹需要重新授权」：这是浏览器版才有的提示，桌面版重新选一次文件夹即可；
  · 导出后找不到文件：导出用的是系统「另存为」对话框，注意看它默认打开的文件夹；
  · 表格里看不到某些列：窗口变窄时列宽会自动压缩，最大化窗口或用横向滚动；
  · 换了新电脑：拷整个「CertVault-桌面版」+ 你的数据文件夹，双击 exe 重新选数据文件夹即可。

十、目录结构（v1.5 起：程序、数据两个平级文件夹）
  CertVault-桌面版\
    CertVault.exe                    主程序（双击运行）
    CertVault.exe.config             运行配置（.NET 4.8 兼容）
    Microsoft.Web.WebView2.*.dll     界面渲染组件
    WebView2Loader.dll               界面渲染组件
    app\                             界面文件（勿删、勿改名）
      index.html  style.css  core.js  store.js  app.js  bridge.js
      vendor\xlsx.full.min.js        Excel 读写组件（本地打包，不联网）
      vendor\echarts.min.js          地图渲染组件（Apache ECharts 5.5.1，本地打包）
      vendor\china-geo.js            中国省级地图数据（离线，不联网）

  数据文件夹（默认与程序文件夹同级；也可在设置里另选）\
    data\  images\  backup\


十一、v1.4 更新（2026-11-24）
  · 备份只保留最近 10 份（设置里能看到共几份、多大、最近一份是什么时候）
  · 每天第一次打开会自动备份一份（文件名带 daily）
  · 写文件改成原子写：断电或崩溃后重新打开，会自动从 .tmp 恢复并提示
  · host.json 损坏会自动改名成 host.json.bad-<时间> 留档，程序照常能开
  · 每条截图上限 8 张，超出会提示「已跳过：xxx.png（每条最多 8 张）」
  · Excel 导入空单元格不再清空原有密码 / CA 口令 / 网址 / 账户 / 截止有效期 / 提醒天数（要清空请导入后手工删）
  · 内容没变化的行在预检里单独显示「无变化 N 条」，不再当成覆盖
  · 导出 Excel 的截图列按最多个数生成（4~8 列），表头与图片一一对应

十二、v1.5 更新（2026-11-24）
  · 表格「网址」「账户」两列文字后面各多了一个复制按钮，点一下即复制（鼠标移上去变金色）
  · 交付包改成两个平级文件夹：CertVault-桌面版\（纯程序）、CertVault-数据\（纯数据：data / images / backup）
  · 首次启动若还没记住数据目录，会自动使用程序同级的 CertVault-数据\（没有就自动建 data / images / backup），
    不再强制先弹「选择数据文件夹」；要改目录仍用设置里的「更换数据文件夹」
  · 升级时只需替换「CertVault-桌面版」文件夹，数据文件夹原地不动；换电脑只拷数据文件夹即可
十三、v1.6 更新（2026-11-25）
  · 表格列宽可以自己拖：鼠标移到表头两列之间的分隔线上（指针变成左右箭头），按住左右拖动即可调整该列宽度
  · 双击那条分隔线 = 只把这一列恢复默认；工具栏最右「重置列宽」= 一次恢复全部列
  · 调好的列宽写进数据文件夹 data\settings.json 的 colWidths，下次打开自动恢复（换电脑把数据文件夹拷过去也照样带）
  · 备注列没有拖拽把手，永远自适应剩余宽度；把别的列拉宽时它会变窄，但至少留约 130px，再宽就出现横向滚动条
  · 任何列最窄只能拖到 56px，防止误拖到没了找不回来
