# CertVault 使用说明（v1 便携版）

> 适用对象：不需要懂技术的同事。照着做就能管理 CA 证书和平台账号。
> 程序版本：v1（浏览器便携版）｜文档依据：`docs/工程契约-v1.md`、`需求清单-v3.md`｜更新日期：2026-11-25（桌面版 v1.6，变更见 §0.4）
>
> **一句话：CertVault 是一个“放在文件夹里的 CA 台账”。**
> 双击启动器 → 选一个数据文件夹 → 以后所有记录和截图都保存在这个文件夹里。
> 不联网、不登录、不上传；把整个文件夹拷走，换台电脑就能接着用。

### 0.1.1 导入预检：三块折叠明细，先看清再导入

操作路径：**台账页左上「Excel 导入」→ 选 .xlsx / .xls / .csv → 预检对话框**。

对话框上方仍是三行汇总（新增 N 条 / 覆盖 N 条 / 错误 N 条），下面按情况出现可点击展开的折叠条：

1. **新增明细（N 条）**——列出这次会新加进来的记录（平台名称 + 账户），最多列 15 条，超出显示"其余 N 条已省略"。
2. **覆盖明细（N 条，看改动）**——按「网址 + 账户」匹配到已有记录的，逐条显示：平台名称、账户，以及每个变化字段的 `旧值 → 新值`（如 `截止有效期：2026-02-20 → 2027-02-20`）。
   - **密码、CA 口令只显示「已填写」或「空」**，不显示明文，开会投屏也安全。
   - 内容完全没变的记录标"内容无变化"；记录较多时只展开前若干条，其余显示"已省略"。
3. **错误明细（N 行）**——逐行列出被跳过的行：`第 X 行` + 原因（如"平台名称为空""日期格式不对"）。错误行只跳过自己，其余行照常导入。

看清后点「确认导入」；想改表就取消，回 Excel 改完再重导。

### 0.1.2 顶部 KPI 卡片：点一下就筛到该状态

主界面最上方四张卡：

| 卡片 | 点击后 |
|---|---|
| 平台 / 账号总数 | 清除状态筛选，回到全部记录 |
| 已逾期 | 台账切到「已逾期」标签，只列逾期的 |
| 提醒中 | 只列剩余天数 ≤ 提醒天数的 |
| 未登记有效期 | 只列没填截止有效期的 |

- 点卡片会自动从地图视图切回台账表格，并在右下角提示「筛选：已逾期（N 条）」这类文案。
- 卡片支持键盘：Tab 聚焦后按 Enter / 空格，等同点击。
- 再点「总数」卡（或表格上方「全部」标签）即可恢复。
- 卡片数字随筛选、编辑、导入实时变化。

### 0.1.3 地图跟着数据走，地区可以打字搜

**地图自动刷新**：停在地图视图时做导入（或增删改、改地区），右侧「按地区汇总」和顶部「已定位 N 条」会立即按新数据重算，不用退出地图再进，也不用重启软件。颜色规则不变：红=有逾期、金=提醒中、绿=正常、灰=未登记。

**地区改成可搜组合框**：新增 / 编辑弹窗里的「地区」不再是只能滚动的长下拉：

1. 点进输入框直接打字：输入 `内蒙` 立即筛出「内蒙古」，输入 `广东` 或 `广东省` 都归到「广东」，`北京` / `北京市` 结果一样。
2. 34 个省级行政区都认**短名**（内蒙古）、**官方全名**（内蒙古自治区）、**常用别名**（内蒙、广西壮族）；列表右侧显示对应全名，鼠标点或键盘 ↑↓ + Enter 选中。
3. 右侧「省份」按钮 = 展开完整 34 省列表；「识别」按钮 = 按平台名称 / 网址 / 备注自动猜一个（猜错可改）。
4. 没匹配到会提示"没有匹配的省份，可以直接手动输入"；手填的省份名保存时也会归一（如填"内蒙古自治区"存成"内蒙古"）。

### 0.1.4 托盘与最小化：不再"点下就没了"

| 操作 | v1.3 的表现 |
|---|---|
| **左键单击**系统托盘图标 | 立即显示主窗口（旧版要双击，或右键再点「显示主窗口」） |
| 右键托盘图标 | 菜单：显示主窗口 / 开机自动启动 / 打开程序所在文件夹 / 退出 |
| 点窗口右上角 **关闭 ✕** | 收进托盘，程序继续后台运行，到期提醒照常 |
| 点 **最小化 —** | 只收到任务栏，**不会隐藏**；点任务栏图标即可还原（旧版这里会把窗口藏起来，看起来像关掉了） |

> 一句话：**✕ = 进托盘（还在跑）；— = 任务栏（点得回来）；托盘图标左键一下 = 叫回窗口。**

## 0.2 v1.4 变更（先看这一节）

> v1.4 是**数据安全 + 导入导出细节**的一次收紧：字段、Excel 模板、数据格式都不变，旧数据直接打开即用。

| 变化 | v1.4 现在的做法 |
|---|---|
| 备份保留份数 | 每次备份后自动只留**最近 10 份**，更早的自动删除（旧版会无限增长）。设置抽屉里显示「共 N 份 · 大小 · 最近 <文件名>」 |
| 每天自动备份 | 每天第一次打开数据文件夹时自动备份一份（文件名带 `daily`），24 小时内不重复 |
| 断电/崩溃不丢库 | 写文件改成「先写 .tmp → 原子替换」；万一只剩 .tmp，下次启动自动从 .tmp 恢复并提示「检测到上次写入中断，已自动恢复」 |
| 配置文件损坏 | `host.json` 读不出来时自动改名成 `host.json.bad-<时间>` 留档，程序正常进演示模式，不会崩 |
| 每条截图上限 | **每条最多 8 张**；新增与导入都按 8 截断，超出时提示里会列出被跳过的文件名 |
| Excel 导入空单元格 | **空单元格不再清空原有内容**（旧版会把密码 / CA 口令 / 网址 / 账户 / 截止有效期 / 提醒天数清掉）。要清空某项，导入后在编辑框里手工删 |
| 导入预检「无变化」 | 内容完全没变的行不再算「覆盖」，预检里单独显示「无变化 N 条」 |
| Excel 导出截图列 | 截图列按当前记录里最多的截图数生成（4~8 列），8 张图的记录导出后「截图 1~8」表头与图片一一对应 |
| 保存 / 删除顺序 | 先写盘成功再删图片；写盘失败不会留下「记录没了但图还在」的半套数据 |

## 1. 这是什么

CertVault 用来记录公司各类 CA 证书、招投标平台、采购系统的账号台账，并提前提醒到期时间。每条记录包含：

| 字段 | 是否必填 | 说明 |
|---|---|---|
| 平台名称 | **是** | 如“示例采购平台” |
| 网址 | 否 | 登录地址，复制后可直接在浏览器打开 |
| 账户 | 否 | 登录账号 |
| 密码 | 否 | 默认显示为圆点，可查看、可复制 |
| CA 证书口令 | 否 | 没有 CA 可留空，或写“未办理 CA” |
| 截止有效期 | 否 | 留空 = “未登记”，不参与提醒 |
| 提醒天数 | 否 | 提前多少天变“提醒中”，默认 60，可填 1–365 |
| 备注 | 否 | 手机号、办理渠道、注意事项等 |
| 地区 | 否 | 省级简称（北京/内蒙古/…），填了才会出现在地图上；编辑框里可点“识别”自动猜 |
| 截图 | 否 | **每条可以放多张**平台操作截图 |

它是一个**免安装的小工具**：整个文件夹拷到任何 Windows 电脑，双击就能用；数据全部在你选定的文件夹里，不依赖服务器，也不上传到任何地方。

## 2. 第一次使用（约 2 分钟）

### 第 1 步：把文件夹放好

把交付给你的**整个文件夹**放到固定位置，例如：

```text
D:\CertVault\
├─ app\                     ← 程序文件，不要删
├─ data\                    ← 你的数据（首次使用后自动生成）
├─ images\                  ← 你的截图（首次使用后自动生成）
├─ backup\                  ← 自动备份（首次使用后自动生成）
└─ 启动 CertVault.bat        ← 双击这个
```

> 建议就放在 `D:\CertVault`。路径里有中文、空格都没关系。
> 不要放在 `C:\Program Files` 这类只读位置，也不要放在会被系统清理的临时目录。

### 第 2 步：双击启动

双击 `启动 CertVault.bat`。

- 会弹出**一个独立窗口**（Microsoft Edge 的“应用窗口”，没有地址栏和标签栏，看起来就像一个软件）。
- 如果电脑没有 Edge，会自动用 Chrome；两个都没有，就用系统默认浏览器打开（窗口上方有地址栏，功能相同，只是没那么像软件）。
- 第一次打开可能显示 **17 条演示数据**，并提示“未连接文件夹”。演示数据是假的，用来熟悉界面。

### 推荐双击启动器，也可以直接双击 index.html

两种方式都能正常打开、读写同一份数据，区别只在“外观”：

- **推荐：双击 `启动 CertVault.bat`**。它会用 Edge/Chrome 的“应用窗口”打开，**没有地址栏和标签栏**，看起来像一个独立软件；路径含中文、空格都没问题。
- **也可以：直接双击 `app\index.html`**。用系统默认浏览器打开，窗口上方会**带地址栏**，功能和用启动器完全一样，只是没那么像软件。
- 如果电脑没有 Edge，启动器会自动换 Chrome；两个都没有就用系统默认浏览器（带地址栏，功能相同）。
- 以后部署到 NAS（用 `http://` / `https://` 地址访问）时，两种方式都不再需要启动器，直接访问管理员发的网址即可。

> **一句话：推荐双击启动器（无地址栏更像软件）；直接双击 index.html 也能用，只是会看到地址栏。**

### 第 3 步：选择数据文件夹并授权

第一次要先“连接”一个数据文件夹。当前版本没有单独的“连接”按钮，入口在第一次保存时：

1. 点工具栏 **“新增”**，填好平台名称（其他字段可先不填），点 **“保存”**。
2. 会弹出提示框 **“需要先连接数据文件夹”**，正文会说明当前是 17 条演示数据。点 **“选择数据文件夹”**（点“继续看演示”则放弃保存）。
3. 在弹出的文件夹选择框里，选择 `D:\CertVault`（就是刚才放程序的那个文件夹），点“选择文件夹”。
4. 浏览器会弹出类似 **“要允许此网站查看和修改文件吗？”** 的提示 → 点 **“允许”**。
5. 连接成功后，刚才那条记录会直接保存：顶栏显示你的文件夹路径，演示数据消失，表格变成你自己的台账。
6. 以后打开，程序会自动恢复到上次的文件夹，不需要重复授权。

> 若顶栏显示 **“演示数据 · 待授权”**（上次的文件夹需要重新授权）或右上角出现 **“重新授权”** 按钮，点它并允许即可；之前的记录不会丢。
> 连接后自动创建 `data\`、`images\`、`backup\` 三个子文件夹，都在你选的文件夹里面。

### 首次使用检查表

| 检查项 | 正常表现 |
|---|---|
| 启动器 | 独立窗口打开，看不到地址栏（若显示地址栏，说明走的是默认浏览器或直接双击了 index.html，也正常） |
| 直接打开 | 直接双击 `app\index.html` 也能用，只是窗口上方有地址栏 |
| 连接文件夹 | 顶栏显示文件夹路径，例如 `D:\CertVault` |
| 授权 | 弹窗中点过“允许”；若当时点了“取消”，再点一次“保存”走一遍连接流程，或点右上角“重新授权” |
| 演示数据 | 连接文件夹后应消失；若仍是 17 条示例，说明没连接成功 |
| 文件夹内容 | 选完文件夹后，里面自动出现 `data\`、`images\`、`backup\` 三个子文件夹 |

> **重要：** 浏览器只支持 Microsoft Edge 或 Google Chrome（Chromium 内核）。
> 不要用 IE、Firefox、360 浏览器的“兼容模式”打开，否则“选择文件夹/授权”功能不可用。
> 直接双击 `app\index.html` 也能用，只是窗口带地址栏；推荐双击启动器（无地址栏，更像软件）。
>
> 授权记录保存在浏览器里。换电脑、换浏览器、清理浏览器数据后，需要**重新选一次文件夹并点“允许”**，数据本身不会丢。

| 顶栏 | 程序名、数据文件夹、提醒铃铛、操作日志、设置 | 铃铛上的数字 = 已逾期 + 提醒中的条数 |
| KPI 四卡 | 平台/账号总数、已逾期、提醒中、未登记有效期 | 点一点心里有数，数字随数据实时变化 |
| 工具栏 | 新增、编辑、删除、取消提醒、恢复提醒、导出模板、Excel 导入、全量导出、显示密码 | 主要操作都在这里 |
| 筛选标签 | 全部 / 已逾期 / 提醒中 / 未登记 | 每个标签后面有数量；点一下只看这一类 |
| 搜索框 | 搜索平台名称、网址、账户、备注 | 不区分大小写；右侧按钮可一键清空 |

### 表格 12 列（从左到右）

勾选 ｜ 序号 ｜ 平台名称（第二行小字是域名）｜ 网址 ｜ 账户 ｜ 密码 ｜ CA 口令 ｜ 截止有效期 ｜ 到期状态 ｜ 提醒 ｜ 截图 ｜ 备注

- **序号**：只是当前视图的行号，不存进数据、也不会导出。删除后会自动重排，永远连续。
- **密码 / CA 口令**：默认显示为圆点，可复制；点工具栏“显示密码”可临时看明文。
- **到期状态**：彩色徽章（灰 = 未登记，绿 = 正常，黄 = 提醒中，红 = 已逾期）。
- **提醒**：显示提前多少天提醒；已取消提醒的记录会标“已关闭”。
- **截图**：显示第一张缩略图和数量小角标。
- **打开详情**：**单击表格中任意一行的空白处**，右侧会滑出“记录详情”抽屉（平台账户、密码、CA 口令、到期信息、截图墙）；勾选框只负责多选，不会打开详情。

### 底部状态栏

| 项目 | 说明 |
|---|---|
| 共 N 条 / 已选 M 条 | 当前筛选结果总数与勾选数 |
| 数据目录 | 你选择的数据文件夹 |

## 4. 日常操作

### 4.1 新增一条记录

1. 点工具栏 **“新增”**。
2. 填写各字段：**平台名称必填**，其余可空。
3. “截止有效期”点右侧日历图标选择日期；“提醒天数”默认 60，可改 1–365；“剩余天数”会自动显示（未填日期时显示“未登记”）。
4. 有截图就拖进“平台操作截图”区域，或点“+ 上传截图”。
5. 点 **“保存”**。
6. 要连续录入多条，点 **“保存并继续录入”**：保存后弹窗不关闭、字段清空，直接录下一条。

> 记录会追加到列表最后一行，序号自动接上。

### 4.2 编辑一条记录

- 勾选 **1 条** → 点工具栏“编辑”；
- 或者在表格行上点右键 → “编辑”；
- 或者单击表格行打开右侧详情抽屉，在抽屉底部点“编辑”。

改完点“保存”即生效。编辑弹窗里也能增删截图（截图要等保存后才真正写入磁盘）。

### 4.3 删除记录（支持多选）

1. 勾选要删的行（表头复选框 = 全选当前列表）。
2. 点工具栏 **“删除”** → 在确认框点“确定”。
3. 程序会**先自动备份**到 `backup\`，再删除记录及其截图目录。
4. 删除后序号自动重排，仍是 1、2、3……连续。

> 删除没有“回收站”，但删除前有自动备份（见第 7 节）。误删可以按第 7.2 节恢复。

### 4.4 搜索与筛选

- **搜索**：在搜索框输入平台名、网址、账户或备注的任意片段，按回车或边打边筛；点“清空”恢复。
- **筛选**：点“全部 / 已逾期 / 提醒中 / 未登记”标签，只看其中一类。
- 搜索和筛选可以**同时使用**；筛选/搜索后，序号从 1 开始连续编号（只是行号，不影响数据）。
- KPI 卡和筛选标签上的数字始终按全部数据统计。

### 4.5 右键复制（6 个字段）

在表格任意一行上点**鼠标右键**，菜单里可以复制：

| 菜单项 | 复制的内容 |
|---|---|
| 复制平台名称 | 平台名称 |
| 复制网址 | 网址 |
| 复制账户 | 登录账户 |
| 复制密码 | 登录密码（不用先显示明文，也能复制） |
| 复制 CA 口令 | CA 证书口令 |
| 复制截止有效期 | 截止日期，格式 `YYYY-MM-DD` |

菜单里还有“编辑”“删除”等操作。复制成功后页面会提示“已复制：账户”之类的信息。

> **剪贴板会自动清空：** 复制后约 30 秒，如果剪贴板里还是刚才复制的内容，程序会把它清空，避免密码一直留在剪贴板。如果这期间你复制了别的东西，则不会动它。
> Windows 自带的“剪贴板历史（Win+V）”无法被本程序控制，涉密口令复制后请留意清空系统剪贴板历史。

### 4.6 显示 / 隐藏密码

- 点工具栏 **“显示密码”** 可以全局切换明文/圆点。
- 这个开关**只影响当前页面**，不会保存，也不会改变数据；刷新或重开页面后自动恢复为圆点。
- 只想复制不想看明文时，直接用右键菜单“复制密码”即可。

### 4.7 截图（每条可多张）

**添加：** 编辑弹窗里，把图片**拖进**截图区域，或点“+ 上传截图”选择文件（可多选，一次可以传多张）。

- 单张图片 **≤ 8MB**，超过的会被跳过并提示。
- 每条记录可以放多张截图；v1 没有单独限制总张数，但截图越多整个文件夹越大，备份/拷贝越慢，建议只放必要的图。
- 支持 PNG / JPG / WebP 等常见图片格式。
- 截图保存在数据文件夹的 `images\<记录ID>\` 里，数据库里只存文件名和宽高。

**查看：** 表格“截图”列显示第一张缩略图和数量；**单击该行**打开右侧详情抽屉，就能看到全部截图的“截图墙”（编辑弹窗里也能看）；点击任意一张看原图（大图），长截图可上下滚动。

**删除：** 在编辑弹窗里，把鼠标移到缩略图上，点右上角 **×** 移除；**再点“保存”才真正生效**。删除整条记录时，它的截图目录会一起删掉。

> 本版本不做 OCR、不自动裁切，截图按原样保存。有效期需要手工填写。

### 4.8 录完一条后的自检

| 检查 | 正常表现 |
|---|---|
| 平台名称 | 已填（必填） |
| 到期状态 | 与日期相符（见第 5 节） |
| 截图 | 缩略图能显示，数量正确 |
| 提醒 | 需要提醒的保持“提醒中”；不需要的可以点“取消提醒” |

## 5. 到期状态与提醒怎么算

### 5.1 剩余天数与四种状态

**剩余天数 = 截止有效期 − 今天**，按自然日计算（今天到期 = 0 天，昨天到期 = -1 天，显示为逾期 1 天）。

| 状态 | 颜色 | 判定条件（以提醒天数 60 天为例） | 显示示例 |
|---|---|---|---|
| 未登记 | 灰 | 没填截止有效期，或日期无效 | 未登记 |
| 正常 | 绿 | 剩余天数 > 提醒天数（如 61 天） | 正常 61 天 |
| 提醒中 | 黄 | 0 ≤ 剩余天数 ≤ 提醒天数（如 0 或 60 天） | 提醒 60 天 |
| 已逾期 | 红 | 剩余天数 < 0 | 已逾期（逾期 1 天） |

- 提醒天数**每条记录单独设置**，默认 60 天，范围 1–365。
- 未登记的记录不参与提醒，补齐日期后自动纳入。
- 修改日期或提醒天数后，状态立即重新计算。

### 5.2 提醒弹窗什么时候出现

- 打开页面时会检查一次；之后页面开着时**每 15 分钟**静默重算一次（重算本身不弹窗）。
- 当存在“提醒中”或“已逾期”且**没有取消提醒**的记录时，启动后会弹出“到期提醒”列表。
- 关掉弹窗后不会立刻再弹，要等**冷却间隔**（设置页可改为 1 / 4 / 12 / 24 小时或“每天一次”，默认 12 小时）。
- 弹窗里的三个按钮：

| 按钮 | 作用 | 下次弹窗时间 |
|---|---|---|
| 稍后提醒 | 先不看，过一会儿再提醒 | 约 1 小时后 |
| 今天不再提醒 | 今天不再打扰 | 明天 |
| 知道了 | 关闭弹窗 | 按设置的冷却间隔 |

- 点弹窗里的任意一条记录，会跳到该记录所在行/详情。
- 弹窗会列出所有“已逾期”和“提醒中”的记录，例如「已逾期 322 天」「提醒 27 天」，一眼能看出哪几条最急。

### 5.3 取消提醒 / 恢复提醒

- 勾选记录后点工具栏 **“取消提醒”**（或详情/右键菜单）：这条不再参与弹窗。
- **状态照常计算**：该是“提醒中”还是“提醒中”，该逾期还是逾期，只是不弹窗。
- 想重新提醒时，勾选后点 **“恢复提醒”**。
- 表格“提醒”列会显示“已关闭”，一眼能看出哪些被静音了。

> 提醒只在**页面开着**时生效。关掉窗口后没有系统通知，这是浏览器版的限制，详见第 11 节。

## 6. 导入与导出（v1.2：Excel .xlsx；兼容 CSV）

> v1.2 桌面版直接读写 **Excel（.xlsx）**：导出模板 / 全量导出都生成 xlsx，截图嵌在单元格里；导入支持 .xlsx / .xls / .csv（CSV 要求 UTF-8 BOM）。浏览器版仍是 CSV。
> 真正的 `.xlsx` 直接读写留到桌面版。

### 6.1 模板列名（固定 9 列）

| 列名 | 必填 | 填写说明 |
|---|---|---|
| 平台名称 | **是** | 为空的行导入时会报错并跳过 |
| 网址 | 否 | 如 `https://cg.95306.cn/` |
| 账户 | 否 | 登录账号 |
| 密码 | 否 | 明文填写（导出的文件也会是明文，注意保管） |
| CA口令 | 否 | 没有就留空 |
| 截止有效期 | 否 | 支持 `2026-02-20`、`2026/2/20`、`20260220` 三种写法；非法日期会报错，该行按“未登记”保留 |
| 提醒天数 | 否 | 1–365 的整数；留空或不是数字时按 60 处理 |
| 备注 | 否 | 自由填写 |

### 6.2 导出（把数据交给 Excel）

1. 点工具栏 **“全量导出”**。
2. 浏览器会下载一个 CSV 文件，文件名形如：`CertVault-导出-20261123-1830.csv`。
3. 用 Excel **双击**打开即可，中文不会乱码（文件带 UTF-8 BOM）。

注意：

- 导出的是**全部记录**，不受当前筛选/搜索影响。
- 导出**只含表格数据，不含截图文件**。截图在 `images\` 里，随整个文件夹一起拷走。
- **导出的 CSV 含明文密码和 CA 口令**，只发给可信的同事，不要随手发微信/邮件/网盘分享。
- 以 `=`、`+`、`-`、`@` 开头的文字（例如密码），导出时会自动加一个英文单引号 `'` 前缀，防止被 Excel 当成公式执行；这是正常的安全处理。

### 6.3 导入（把 Excel 里的数据导进来）

1. 点工具栏 **“导出模板”**，得到只有表头的 CSV 模板（也可以先“全量导出”现有数据再修改）。
2. 用 Excel 填好，**另存为“CSV UTF-8（逗号分隔）(*.csv)”**。
3. 点工具栏 **“Excel 导入”**，选择这个 CSV 文件。
4. 程序会先弹出**预检**：`新增 N 条 / 覆盖 M 条 / 错误 K 条`，错误会逐行列出来（最多显示 20 行）。例如：`新增 2 条 / 覆盖 0 条 / 错误 1 条`，并提示「第 4 行：平台名称为空，已跳过」。
5. 确认无误点“确定”：程序先自动备份，再写入；点“取消”则什么都不改。

**判重规则：网址 + 账户**（忽略大小写和首尾空格）。

| 情况 | 结果 |
|---|---|
| 网址和账户都与已有记录相同 | 覆盖原记录 |
| 网址或账户不同，或新记录 | 新增一条 |
| 网址和账户都是空的 | 不算重复，每次导入都会新增（请至少填一项） |

- 覆盖时保留原记录的**内部 ID、创建时间、截图、取消提醒标记**，只更新导入表格里的内容。
- 导入**不会删除**系统里原有的记录；同一个文件重复导入 = 反复更新，不会翻倍。
- 想批量修改现有记录，建议顺序：**先导出 → 在 CSV 里改 → 再导入**，这样每一列都是完整内容。
- 一次要导入很多条（例如超过 200 条）时，建议**分几批**导入：v1 不会自动分批，也不会阻止你一次导入，但分批更容易核对预检里的新增/覆盖/错误，出错时回滚范围也小。

### 6.4 逐行错误怎么处理（不会整批失败）

| 错误情况 | 程序的处理 | 你该怎么做 |
|---|---|---|
| 平台名称为空 | 该行跳过并报错误行号 | 补上平台名称后重新导入 |
| 日期非法（如 2026-13-40） | 该行保留，截止有效期变成“未登记”，并报错 | 改成正确日期再导入 |
| 提醒天数不是数字 | 按默认 60 天处理 | 一般无需处理 |
| 列数不足 | 缺的列按空值处理 | 用模板列名核对 |

### 6.5 CSV / Excel 注意事项

| 注意点 | 说明 |
|---|---|
| 编码 | 必须是 **UTF-8（带 BOM）**。用 Excel 的“CSV UTF-8（逗号分隔）”或记事本“UTF-8”另存；用 ANSI/GBK 保存会乱码 |
| 列名 | 必须使用上面的 8 个列名；**列顺序可以变**，多出来的列会被忽略，缺的列按空值 |
| 日期 | 建议把该列设置成“文本”后填 `YYYY-MM-DD`；三种日期写法都支持 |
| 长数字账户 | Excel 可能把 18 位账号变成科学计数法或吃掉开头 0：导入前把该列设为“文本” |
| 密码里的逗号/引号/换行 | 用 Excel 保存时会自动加引号，不需要手工处理 |
| 密码以 `=` 开头 | 在 Excel 里会被当公式：把单元格设为“文本”，或前面加一个英文单引号 |
| 文件被占用 | 导入前先在 Excel 里关闭该 CSV，否则可能读取失败 |

### 6.6 导入示例（可直接存成 `导入示例.csv`）

```csv
平台名称,网址,账户,密码,CA口令,截止有效期,提醒天数,备注
测试平台A,https://a.example.com/,userA,passA,123456,2026-12-31,60,导入测试
测试平台B,https://b.example.com/,userB,passB,,2026/6/1,30,日期用斜杠
测试平台C,https://c.example.com/,userC,,,2026-01-01,60,没有 CA 口令
```

## 7. 备份、搬走与恢复

### 7.1 自动备份在哪里

- 每次**删除记录**、**导入数据**之前，程序自动把当时的 `data\certvault.json` 复制一份到 `backup\`。
- 设置页还有 **“立即备份”** 按钮，重要操作前可以手动点一下。
- 备份文件名格式：`<日期>-<时间>-<原因>.json`，例如：

```text
D:\CertVault\backup\20261123-180000-delete.json      ← 删除前自动备份
D:\CertVault\backup\20261123-183015-import.json      ← 导入前自动备份
```

- 备份文件是纯文本 JSON，可以用记事本打开查看；**备份不含截图图片**（截图在 `images\` 里）。

### 7.2 恢复某次备份（误删/改坏了）

1. **先关闭 CertVault 页面**（很重要，避免同时写文件）。
2. 打开 `D:\CertVault\data\`，把当前的 `certvault.json` 复制一份留底（可改名为 `certvault.json.bak`）。
3. 打开 `D:\CertVault\backup\`，选一个时间合适的 `.json` 文件，**复制**到 `data\` 文件夹。
4. 把复制过来的文件改名为 `certvault.json`（覆盖第 2 步留底之外的原文件）。
5. 重新双击启动器打开，数据就回到那个备份时间点。

> 不要用 Excel / Word 打开或修改 `certvault.json`；它只是文本，但格式被改坏会导致打不开。

### 7.3 搬到新电脑 / 换文件夹

1. **关闭 CertVault 窗口**（等 2 秒，确保文件写完）。
2. 拷贝**整个文件夹**到新电脑/新位置（必须包含 `data\`、`images\`、`backup\`、`app\` 和启动器）。
3. 在新电脑双击 `启动 CertVault.bat`。
4. 连接数据文件夹：点“新增”→填平台名称→“保存”，在提示框点 **“选择数据文件夹”**，选拷贝后的文件夹并点“允许”；若右上角已有 **“重新授权”** 按钮，直接点它授权即可。
5. 检查：条数一致、随便打开一条能看到截图、KPI 数字正常。

> 浏览器的“授权记录”不会跟着文件夹走，**换电脑后必须重新授权一次**，数据不会丢。
> 用 U 盘/U 盘拷走前，先关闭页面再拔出 U 盘。

### 7.4 备份建议（养成习惯）

| 频率 | 做什么 |
|---|---|
| 每周 | 把**整个数据文件夹**（含 images）复制到移动硬盘或公司备份盘 |
| 重要操作前 | 点设置页“立即备份” |
| 每月 | 抽查一次：随便打开一个 backup 里的 .json，确认能看懂、日期正确 |
| 换电脑/交接 | 整个文件夹拷贝 + 新电脑重新授权，交接后原电脑上的文件夹归档 |

## 8. 多人使用

### 推荐做法：每人一份文件夹

- 每位同事拷贝一份完整的程序 + 数据文件夹，各自维护自己的台账。
- 互不影响、不会互相覆盖，最简单也最稳。
- 需要汇总时用**导出/导入**合并（见下）。

### 不推荐：多人同时打开同一份文件夹

浏览器版**没有真正的文件锁**。如果两个窗口同时打开同一份数据文件夹，后保存的人会覆盖先保存的人，可能丢数据。

如果确实要把文件夹放在共享盘/NAS 上：

1. 约定**同一时间只有一个人打开**，其他人等对方关掉窗口后再开；
2. 正在使用的人先完成保存，再让别人打开；
3. 重要数据仍要按第 7.4 节单独备份。

### 怎么合并两个人的数据

1. 各自在工具栏点 **“导出”**，得到 CSV；
2. 由一个人打开自己的 CertVault，点 **“导入”**，选对方的 CSV；
3. 按“网址 + 账户”判重：相同的会覆盖，不同的会新增；
4. 导入前会自动备份；如果结果不对，可以按第 7.2 节从备份恢复。

> 未来版本（NAS/桌面阶段）会提供共享目录下的修改日志与通知；v1 先按“每人一份”使用。

## 9. 设置页说明

点顶栏的齿轮图标进入设置。设置保存在 `data\settings.json`，跟文件夹一起走。

| 设置项 | v1 说明 |

| 开机后台自启动 | 设置里是**预留开关**；浏览器版不生效，需要开机用时请手动双击启动器 |

## 10. 常见问题（FAQ）

| 问题 | 原因与处理 |
|---|---|
| 双击启动器没反应 / 窗口一闪就没了 | 确认 `启动 CertVault.bat` 和 `app\` 文件夹在同一目录；被杀毒软件拦截时先放行；用记事本检查 bat 是否被改坏 |
| 窗口上方有地址栏，不像软件 | 说明是用普通浏览器窗口打开的（没找到 Edge/Chrome，或直接双击了 index.html）。功能完全一样；装 Microsoft Edge 后双击启动器即可获得无地址栏的应用窗口 |
| 提示“未连接文件夹” / 看不到自己的数据 | 点“新增”→填平台名称→“保存”，在提示框里点“选择数据文件夹”，选原来的数据文件夹并“允许”；有“重新授权”按钮时也可点它 |
| 每次打开都要重新授权 | 浏览器把授权忘了（清理过缓存/隐私设置/换浏览器）。点右上角“重新授权”并允许即可；也可以把该页面设为信任 |
| 直接双击 app\index.html 能用吗 | 能。功能和用启动器完全一样，只是窗口上方会带地址栏；推荐双击启动器获得无地址栏窗口（见第 2 节） |
| 页面空白 / 排版乱了 | 用 Edge 或 Chrome 最新版，不要用 IE/不兼容模式；按 F5 刷新；仍不行换成 Edge 再试；仍打不开请把截图发给管理员 |
| 导入后中文乱码 | CSV 不是 UTF-8 BOM。用 Excel“CSV UTF-8（逗号分隔）”重新另存，或用模板重新填写 |
| 导入提示“错误 K 条” | 看预检里的错误行号；常见是平台名称为空、日期写错、列名不对 |
| 导入后条数没变 / 变少了 | 判重是“网址+账户”，相同会被覆盖而不是新增；先把 CSV 里的网址+账户补全 |
| 截图显示不出来 | 截图文件被手工删了，或拷文件夹时漏了 `images\` 目录。从备份/原文件夹把 `images\` 补回来 |
| 密码忘了怎么办 | 本程序不联网、没有找回功能，密码只能由你自己记录；请向管理员或原平台找回 |
| 数据保存在哪？能直接看吗？ | 在数据文件夹的 `data\certvault.json`，是文本文件；可以打开看，但**不要手改**（格式坏了会打不开） |
| 杀毒软件报警 | 程序是纯本地的 HTML/JS 文件，不联网；可把文件夹加入白名单 |
| 能不能发到手机上用？ | 不能。浏览器版只支持电脑上的 Edge/Chrome（文件访问接口的限制） |
| 关掉页面还会提醒吗？ | 不会。提醒只在页面打开时检查；需要提醒时让页面开着（见第 11 节） |
| 关掉窗口后数据还在吗？ | 在。数据都保存在数据文件夹里，关页面不影响；重新双击启动器打开即可，记录、设置、截图都在 |

## 11. v1 已知边界（务必读一遍）

v1 是**浏览器便携版**：免安装、纯本地、拷走即用，但有些“软件级”能力浏览器做不到。下面这些**不是 bug**，请知悉：

| 能力 | v1 现状 | 替代做法 / 后续计划 |
|---|---|---|
| 托盘常驻（关窗口后仍在后台跑） | **做不到**。关掉页面 = 程序退出，提醒停止 | 需要提醒时保持页面开着；后期桌面封装版实现 |
| 开机自动启动 | **做不到**。需要手动双击启动器 | 可以自己建桌面快捷方式；桌面版实现 |
| 真正的并发文件锁 / 单实例 | **做不到**。浏览器无法阻止第二个窗口同时写同一文件夹 | **每人一份文件夹**；共享盘约定同一时间只一人使用；桌面版实现单实例锁 |
| 后台检查 / 系统通知 / 邮件 / 企微推送 | **做不到**。只有页面开着时才会弹提醒窗 | 页面开着时靠弹窗；通知类功能留到 NAS/桌面阶段 |
| 直接读写 `.xlsx` | 不支持，用 CSV（UTF-8 BOM，Excel 可直接打开） | 桌面版再做 .xlsx |
| 一次导入很多条（如超过 200 条） | v1 **不强制分批**、没有“导入过多”的提示；一次导入全部也可以 | 建议每批 ≤200 条分批导入，预检更好核对；错误行号也更容易定位 |
| 密码加密存储 | **未加密**：`data\certvault.json` 里是明文 | 给数据文件夹设 Windows 权限（只本人可读）；不要把文件夹放公共共享目录、不要外发 |
| 截图 OCR / 自动读证书有效期 | **不做**，有效期一律手填 | 保持人工登记，避免误读证书 |
| 云同步 / 多端实时 | 不支持；放 OneDrive 等同步盘可能产生冲突文件 | 单机使用；需多人共享时按第 8 节约定 |
| NAS 共享 + 修改日志 + 通知 | v1 不做，留到 NAS 阶段 | 先把数据按“每人一份”管好，后续版本升级 |
| 回收站 / 一键还原 | 没有回收站；删除后靠 `backup\` 里的 JSON 手工恢复 | 见第 7.2 节；重要操作先“立即备份” |
| 直接双击 index.html | **能用**，但窗口带地址栏；只有 Edge/Chrome 的“应用窗口”模式才会隐藏地址栏 | 推荐双击启动器；两种方式读写同一份数据，NAS 阶段直接访问网址 |
| 导出截图 / 打包 | v1.2 导出 xlsx 会内嵌截图（每行第 K 列起） | 图片多时 xlsx 会变大，也可以整个文件夹拷走 |
| 打印 / 报表 | 无内置打印模板 | 导出 CSV 用 Excel 排版打印 |
| 手机 / 平板 | 不支持（浏览器文件访问接口限制） | 电脑上使用 |

> 一句话：**v1 不假装有桌面软件的能力。** 托盘、自启、真正的文件锁留给桌面封装阶段；共享修改日志与通知留给 NAS 阶段。

## 12. 数据文件夹里都有什么

假设数据文件夹是 `D:\CertVault`：

```text
D:\CertVault\
├─ app\                                   ← 程序文件（index.html / core.js / store.js / app.js 等），不要删
├─ 启动 CertVault.bat                       ← 双击启动
├─ data\
│  ├─ certvault.json                       ← 全部记录（JSON 文本，勿手改）
│  ├─ settings.json                        ← 设置与“上次弹窗时间”
│  ├─ audit.json                           ← 最近 200 条操作日志
│  └─ .lock                                ← 运行标记文件（可能看不到，不用管）
├─ images\
│  └─ r_lx3k9f2a\                          ← 某条记录的截图目录（记录内部 ID）
│     ├─ 20261123-153000-a1b2.png
│     └─ 20261123-153012-c3d4.png
└─ backup\
   ├─ 20261123-180000-delete.json          ← 删除前的自动备份
   └─ 20261123-183015-import.json          ← 导入前的自动备份
```

| 文件/目录 | 是什么 | 可以删吗 |
|---|---|---|
| `app\` | 程序本体 | **不要删** |
| `启动 CertVault.bat` | 启动器 | **不要删** |
| `data\certvault.json` | 你的全部台账 | 不要手改；备份时整个拷 |
| `data\settings.json` | 设置 | 删了会恢复默认，不丢记录 |
| `data\audit.json` | 操作日志 | 可删，不影响数据 |
| `images\` | 所有截图 | 不要删，删了详情里截图打不开 |
| `backup\` | 自动备份 | 建议保留最近若干份；确认不需要再清理 |
| `data\.lock` | 程序运行标记 | 程序自己管理，不用管 |

> 数据文件夹和程序文件夹可以是同一个（推荐，拷一个文件夹就完整），也可以分开（例如数据放 U 盘）。**如果分开，搬走时两个文件夹都要拷。**

## 14. 一页速查（可以打印贴在工位）

**三个必做**

1. 双击 `启动 CertVault.bat`；
2. 点“新增”→填平台名称→“保存”，在提示框点 **“选择数据文件夹”**，选 `D:\CertVault`（或自己的数据文件夹）；
3. 浏览器弹窗点 **“允许”**。

**三个不要**

1. 不要两个人同时打开同一份数据文件夹；
2. 不要在页面开着时手工修改 `data` 里的文件；
3. 不要用 IE / Firefox / 360 兼容模式打开。

**三个定期**

1. 每周：把整个数据文件夹复制到移动硬盘/备份盘（含 `images`）；
2. 重要操作前：设置页点“立即备份”；
3. 每月：抽查一个 `backup\` 里的备份文件能否打开。

**遇到问题**

1. 先关闭页面，重新双击启动器；
2. 查第 10 节 FAQ；
3. 仍解决不了：把**页面截图 + 提示文字**发给管理员，并说明你最后一次操作是什么。
