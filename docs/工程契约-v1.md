# CertVault v1 工程契约（唯一事实来源）

> 本文件由 Lead 编写，所有 teammate 必须先读本文件再动手。契约锁定后不得单方面修改；确需变更只改自己 scope 内的实现，并在完成报告里说明。

## 0. 产品与形态
CertVault = 公司 CA 证书 / 平台账号台账 + 到期提醒 + 多张操作截图。v1 交付**免安装便携版**：用 Edge/Chrome 打开 `app/index.html`，用户选一个数据文件夹，数据与图片都落在该文件夹内，整个文件夹可拷走。

已验证事实：Edge 以 `file://` 打开时 `isSecureContext === true` 且 `window.showDirectoryPicker` 存在，因此 **File System Access API 可用**。

明确约束：
- 纯静态，**禁止任何 npm 运行时依赖**，禁止打包/构建步骤。
  - ⚠ 架构修订（集成验收期实测后拍板）：Edge 145+ 在 `file://` 下**不执行**外部 `<script type="module">`（加 `--allow-file-access-from-files` 才执行），会让用户双击看到白屏。因此实际实现改为 **classic script + 全局命名空间**：`index.html` 依次加载 `core.js`（`window.CVCore`）→ `store.js`（`window.CVStore`）→ `app.js`，双击即可运行、不需要任何浏览器启动参数。本条早期的 ES module 要求已作废。
- 托盘常驻、开机自启、单实例文件锁在浏览器里**做不到**，v1 用横幅与文档如实说明，不假装实现。
- Excel 交互先用 CSV（UTF-8 BOM，Excel 双击可直接打开）。真正的 .xlsx 留到桌面封装阶段。

## 2. 数据模型
record 对象：
```js
{
  id: "r_lx3k9f2a",              // 内部主键，永不变、不复用
  name: "示例平台", url: "https://demo.example.com/", account: "", password: "", caPassword: "",
  expiry: "2026-05-10",          // "YYYY-MM-DD" 或 ""
  remindDays: 60,                // 1..365
  note: "",
  images: [{ file: "20261123-a1b2.png", w: 1280, h: 720, size: 480123, addedAt: "ISO" }],
  remindOff: false,              // true = 取消提醒：不弹窗，但状态照算
  createdAt: "ISO", updatedAt: "ISO"
}
```
磁盘布局（用户选的根目录 R）：
```
R/data/certvault.json     { "version":1, "updatedAt":"ISO", "records":[...] }
R/data/settings.json      { "version":1, "trayMinimize":true, "autostart":false, "popupIntervalHours":12, "backupBeforeDanger":true, "lastPopupAt":"ISO|null", "lastOpen":"ISO" }
R/data/audit.json         { "version":1, "entries":[{ts,action,detail}] }   // 最多 200 条
R/data/.lock              { "id":"...", "ts": 1700000000000 }
R/images/<recordId>/<文件名>
R/backup/<yyyymmdd-HHmmss>-<reason>.json
```

## 3. core.js —— 必须完全一致的导出签名
```js
export const STATUS_LABEL = { none: '未登记', ok: '正常', soon: '提醒中', over: '已逾期' };
export const CSV_HEADER = ['平台名称','网址','账户','密码','CA口令','截止有效期','提醒天数','备注'];
export const DEFAULT_REMIND_DAYS = 60;
export function makeId(prefix = 'r') // 'r_' + base36 时间 + 6 位随机
export function todayStr(now = new Date())                       // 'YYYY-MM-DD'（本地时区）
export function parseDate(str)                                    // 接受 2026-02-20 / 2026/2/20 / 20260220；非法 → null
export function daysLeft(expiry, now = new Date())                // 自然日差（按本地 0 点取整）；空/非法 → null
export function statusOf(record, now = new Date())                // → { key, days, label, text }
export function normalizeRecord(input)                            // 补默认值；remindDays 非法 → 60；images 去重；不造 id 时保留原 id
export function summarize(records, now = new Date())              // → { total, over, soon, ok, none }
export function toCsv(records)                                    // 不含 BOM；字段含逗号/引号/换行时用双引号转义；防公式注入：以 = + - @ 开头的字符串前置 '
export function fromCsv(text)                                     // → { records: partial[], errors: [{line, message}] }
export function dedupeKey(rec)                                    // (url||'').trim().toLowerCase() + '|' + (account||'').trim().toLowerCase()
export function mergeImport(existing, incoming)                   // → { records, added, updated, errors }
```
`statusOf` 判定（务必严格）：
- expiry 空 / `parseDate` 为 null → `{ key:'none', days:null, label:'未登记', text:'—' }`
- `days < 0` → `{ key:'over', days, label:'已逾期', text: '逾期 ' + (-days) + ' 天' }`
- `0 <= days <= remindDays` → `{ key:'soon', days, label:'提醒中', text: '提醒 ' + days + ' 天' }`
- 否则 → `{ key:'ok', days, label:'正常', text: days + ' 天' }`

`fromCsv` 规则：支持表头按名匹配（列顺序可变、缺列忽略、多列表忽略）；`\ufeff` 先去 BOM；平台名称为空的行记 error 并跳过；日期非法记 error 但保留该行（expiry 置 `''`）；`提醒天数` 非数字 → 60。
`mergeImport`：key 命中且不为 `'|'` → 覆盖 incoming 中出现的字段（null/undefined 不覆盖），保留 id/createdAt/images/remindOff；否则新增（`normalizeRecord` 生成 id）。返回的 errors 原样带上入参 errors。

## 4. store.js —— 必须完全一致的导出签名
```js
export class Store {
  static supported()                                  // typeof showDirectoryPicker === 'function'
  static async pick()                                 // showDirectoryPicker({ mode:'readwrite', id:'certvault' })，保存句柄到 IndexedDB(db 'certvault', store 'kv', key 'root')，确保 data/ images/ backup/ 存在；返回 Store
  static async restore()                              // 取句柄 → 若 queryPermission 为 granted 返回 Store，否则返回 Store 实例（其 needsPermission = true）
  get folderName; get needsPermission
  async grant()                                       // requestPermission({mode:'readwrite'})，必须由用户点击触发；返回 boolean
  async readRecords()                                 // 文件不存在 → []
  async writeRecords(records)                         // 覆盖写（缩进 2 的 JSON）
  async readSettings() / async writeSettings(obj)     // 缺省合并 DEFAULT_SETTINGS
  async addImages(recordId, files)                    // 写 images/<id>/<yyyyMMdd-HHmmss>-<rand>.<ext>；createImageBitmap 读宽高（失败则 w/h = 0）；单文件 >8MB 跳过；返回 imageMeta[]
  async deleteImage(recordId, file)
  async deleteRecordImages(recordId)                  // 目录不存在不报错
  async imageBlob(recordId, file)                     // → Blob|null
  async backup(reason)                                // 复制 data/certvault.json → backup/<ts>-<reason>.json；返回文件名或 null
  async lock() / async unlock() / async lockInfo()    // data/.lock {id, ts}；lockInfo() → { held:boolean, stale:boolean, ts:number|null }
  async audit(entry)                                  // 追加 {ts, action, detail}，保留最近 200 条
  async readAudit()
}
export async function downloadText(filename, text, mime = 'text/csv;charset=utf-8')
export function pickTextFile(accept = '.csv')         // 动态创建 <input type=file>，返回 Promise<File|null>
```
错误处理：任何 FS 操作失败都 `throw new Error('中文可读原因')`，由 app.js 捕获成 toast。不要再 console 噪音。

## 6. app.js 必须实现的行为
1. 启动：`Store.restore()` → 未连接则进入**演示模式**（渲染内置 17 条示例数据，顶栏 #folderChip 显示"演示数据 · 未连接文件夹"，任何写操作先提示并触发 `Store.pick()`）；需要重新授权时显示 `#lockBanner`。
2. 渲染：`state.records` + 搜索词 + tab 过滤 → `renderTable()`；行号 = 过滤后 index+1（连续）；`#emptyState` 在 0 行时显示。
3. 选中：点击行切换 `selectedIds`；`#btnEdit` 仅 1 条可点；`#btnDelete` 支持多条；`#table thead .chk-all` 全选。
4. 新增/编辑：填 `#modal` → 保存走 `normalizeRecord` → 若选了新图片先 `store.addImages` → `writeRecords`；`#fRemain` 随 `#fExpiry`/`#fRemindDays` 实时显示"剩余 N 天 / 已逾期 N 天 / 未登记"。`#btnSaveNext` = 保存后清空并保留弹窗。
5. 删除：`confirm` → `store.backup('delete')` → `deleteRecordImages` → 写回。
6. 取消/恢复提醒：切换 `remindOff`，写回，toast 反馈。
7. 右键菜单：行 `contextmenu` 定位 `#ctxMenu`；复制用 `navigator.clipboard.writeText`，toast "已复制：账户"；30 秒后若剪贴板仍是该值则尝试 `writeText('')` 清空（失败静默）。
8. 导入：`pickTextFile` → `fromCsv` → `mergeImport` → 预检弹窗文案 "新增 N 条 / 覆盖 M 条 / 错误 K 条"（错误逐行列出，最多 20 行）→ 确认后 `backup('import')` + 写入。模板导出 = 仅表头 CSV。
9. 导出：全量 CSV（`toCsv`，前置 `\ufeff` BOM，文件名 `CertVault-导出-YYYYMMDD-HHmm.csv`）。
10. 密码显示：`#btnShowPwd` 全局切换（仅内存，不落盘）。
11. 截图：编辑弹窗支持拖放/选择 → 缩略图预览（`URL.createObjectURL`）→ 可删除；详情抽屉显示截图墙，点击打开大图（新窗口/遮罩均可）。未连接文件夹时用 DataURL 预览、提示需连接后才能保存。
12. 提醒：启动 + 每 15 分钟重算；存在 `over|soon` 且未 `remindOff` 且距 `settings.lastPopupAt` 超过 `popupIntervalHours` → 打开 `#remindModal`；三个按钮分别写 `lastPopupAt`（稍后 = +1 小时，今天不再 = 今天 24 点，知道了 = 按 settings 间隔）。
13. 状态栏：总数、选中数、文件夹名、截图总数与体积（未知则 `—`）、"可安全拷走"、上次活动时间。
14. 日志：每次增删改/导入/导出/备份 → `store.audit`；`#logPanel` 渲染最近 200 条。
15. 全局：任何异常 → toast 中文提示，不白屏；`window.onerror` 兜底。
